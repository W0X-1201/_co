# 現代開源 IC EDA 軟體評測報告：veryl2chip（修正版）

**評測標的：** veryl2chip（由 ccc-eda / 陳鍾誠老師團隊開發之開源 EDA 專案）

**線上體驗環境：** [veryl2chip Web IDE](https://ccc-eda.github.io/veryl2chip/)

**原始碼倉庫：** [GitHub - ccc-eda/veryl2chip](https://github.com/ccc-eda/veryl2chip)

## 一、 系統概述與定位

veryl2chip 是一個基於 Rust 語言、結合 Wasm 技術開發的輕量級端到端（End-to-End）數位 IC 設計工具鏈。該專案以現代硬體描述語言 Veryl 為前端，嘗試將編譯器、模擬器、邏輯合成器、FPGA 佈局繞線器及 ASIC 實體設計流程整合至單一系統中。

其最具特色之處在於：將上述工具鏈編譯為 WebAssembly（Wasm），使用者僅需透過現代瀏覽器下載靜態資源即可於客戶端執行工具鏈，完成從 RTL 撰寫到 GDSII 晶片佈局與 FPGA Bitstream 產生的流程。

## 二、 核心技術架構解析

| 階段 / 元件 | 技術實作 | 功能說明 |
|---|---|---|
| 輸入語言 | Veryl HDL (veryl-parser) | 現代化開源硬體描述語言，具備強型別與較為清晰的語意。 |
| 功能模擬 (Sim) | veryl2chip-sim (Wasm) | 事件驅動模擬核心，支援 4-state 向量模擬、`#[test]` 測試台執行與 VCD 波形產生。 |
| 邏輯合成 (Synthesis) | AST Lowering & Tech Mapping | 將 Veryl AST 進行層次展平並對映至基礎邏輯閘或標準元件。 |
| FPGA 後端 | iCE40 / ECP5 P&R | 支援 Lattice iCE40UP5K 佈局繞線，輸出 `.asc`、`.bin` 燒錄檔，並內建虛擬開發板。 |
| ASIC 後端 | SkyWater SKY130 Flow | 執行標準元件放置、繞線及簡易時序評估，最終產生 GDSII、網表等輸出檔案。 |

## 三、 操作體驗測試

本次測試僅針對官方線上 Web IDE 進行功能體驗評估，並非對工具進行大規模效能量測。

### 1. 介面操作體驗
- **視覺佈局：** 類似 VS Code 的介面，整合檔案樹、Monaco 編輯器、終端、波形檢視器及實體佈局視窗。
- **載入效能：** 靜態資源載入後執行於瀏覽器端，初始化速度相當快。

### 2. RTL 撰寫與行為模擬
- 支援以 `#[test]` 定義的單元測試進行模擬。
- 模擬完成後可即時檢視 VCD 波形，並能從錯誤訊息跳轉至對應程式碼行。

### 3. 邏輯合成與閘級模擬
- 可將 RTL 合成為閘級網表並切換至閘級模擬模式。
- 透過相同測試台進行模擬，可驗證合成前後行為一致（需注意：僅為模擬驗證，並非形式等價性檢查）。

### 4. FPGA 流程與虛擬開發板
- 執行 iCE40 流程並產生 Bitstream。
- 內建虛擬開發板可直接載入 Bitstream 並與虛擬開關、LED、7 段顯示器互動。

### 5. ASIC 實體設計與 SKY130 GDSII 匯出
- 支援 SkyWater SKY130 PDK，執行元件放置、繞線及簡易時序評估。
- 可於瀏覽器內預覽佈局圖並匯出 GDSII、Verilog/JSON 等檔案。

## 四、 評測分析：優勢與亮點

- **低門檻的體驗：** 僅需瀏覽器即可體驗大部分數位設計流程，對教學與入門十分友善。
- **端到端整合：** 在單一介面中整合模擬、合成、FPGA 及 ASIC 流程，流程銜接相當流暢。
- **現代化技術棧：** 採用 Rust 與 Wasm，具備良好的執行效能與安全性。
- **開源生態對接：** 選用 Veryl 與 SkyWater SKY130，與當前開源半導體趨勢貼近。

## 五、 現存限制與改進建議

| 限制 | 影響 | 建議 |
|---|---|---|
| 瀏覽器資源限制 | Wasm 記憶體與單執行緒限制，對較大設計（數十萬閘以上）較為吃力。 | 建議以 CLI 版本作為較大規模設計的主要途徑，Web 版定位於教學與原型驗證。 |
| 簡化的實體分析 | 內建的時序評估與設計規則檢查僅為基礎模型，覆蓋率有限。 | 明確標示為「簡易評估」而非 sign-off，並強化關鍵參數的說明。 |
| 語言生態覆蓋 | 僅原生支援 Veryl，對既有 SystemVerilog/Verilog 資產支援較弱。 | 強化 Veryl 與 Verilog 之間的轉譯工具，提升與既有專案的互通性。 |
| 宣傳性描述需釐清 | 部分功能敘述過於絕對（如「符合 DRC 規範」、「確保邏輯等價性」）。 | 應區分「展示功能」與「實際保證」，以客觀用語說明。 |

## 六、 結論

veryl2chip 是一套極具教育意義的現代化開源數位 IC 設計工具鏈。它並非商用 EDA 的直接替代品，而更適合用於數位邏輯教學、開源硬體入門、概念驗證與小型原型設計。

其最大貢獻在於將原本門檻極高的 IC 設計流程整合至瀏覽器中，讓更多人能夠實際體驗從 RTL 到 GDSII 的完整流程。若能釐清其定位並強化對限制的說明，將能更準確地傳達此工具的真實價值。
